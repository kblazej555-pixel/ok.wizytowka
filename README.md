
# Ćwiczenia Kotlin – Etap 1

## Opis projektu

Repozytorium zawiera ćwiczenia wykonane w języku Kotlin
w ramach nauki programowania.

## Etap 1 – Podstawy języka Kotlin

### Ćwiczenie 1 – Dane ucznia

Napisano program przedstawiający ucznia.

Program wyświetla:
- Imię lub pseudonim
- Klasę
- Kierunek kształcenia

W ćwiczeniu wykorzystano zmienne:
- val – zmienna, której nie można ponownie przypisać
- var – zmienna, której wartość można zmienić

### Ćwiczenie 2 – Obliczanie godzin zajęć

Utworzono funkcję obliczGodziny(), która przyjmuje:
- liczbę godzin zajęć tygodniowo
- liczbę tygodni

Funkcja zwraca łączną liczbę godzin.

Przykładowe wyniki:

| Godziny tygodniowo | Tygodnie | Wynik |
|---|---|---|
| 30 | 4 | 120 godzin |
| 35 | 6 | 210 godzin |
